今日名詞解析

4F² 記憶體單元（4F² Cell）

「F」是製程能做出的最小線寬（feature size）。DRAM 每個儲存單元佔的面積，用「幾個 F²」來表示：目前主流 DRAM 是 6F²，4F² 代表同樣的線寬下，每個單元面積縮小約三分之一，同一片晶圓能放更多記憶體。這不是靠更先進的機台把線寬做細，而是改變單元的排列與電晶體結構（例如垂直通道電晶體），所以被視為繞過設備限制、提高密度的路線。今天長鑫存儲宣稱在 4F² 取得進展，TrendForce 估計可提高 30–50% 密度；若屬實且能量產，中國廠在受出口管制、拿不到最先進設備的情況下，仍可能縮小與三星、SK Hynix、Micron 的差距。目前此說法尚未經獨立驗證。

為什麼要懂：記憶體是循環產業，長期獲利取決於供給是否有紀律；新架構會改變「誰能用較低成本擴產」，是判斷記憶體循環高點能維持多久的重要變數。
